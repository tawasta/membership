======================================
Membership Disable Quantity in Product
======================================

This module hides the quantity selector on the product page for
membership products, so a customer can never choose to buy more than
one at a time.

Configuration
=============
\-

Usage
=====

#. Open a membership product's page on the website shop.
#. The quantity selector is not shown; only "Add to Cart" is available.
